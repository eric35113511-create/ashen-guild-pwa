# 灰燼公會 Ashen Guild

一款沒有固定故事主線的瀏覽器回合制 RPG。玩家經營邊境公會，自由選擇委託、組織三人隊伍，在短程遠征中管理生命、技能與戰利品。

- [x] 第三階段：隨機委託、節點遠征、獎勵與公會成長

## 第二輪新增內容

- 四種每日邊境局勢，輪替改變敵我能力與任務收益
- 每場非終點戰鬥後，從三件隨機遺物中選擇一件
- 六種可疊加的遠征遺物，支援攻擊、防禦、治療與技能流派
- 公會紀錄冊統計遠征、勝場及完成委託數
- 四項成就與一次性金幣獎勵
- 舊版瀏覽器存檔自動補齊新欄位

> 第五階段完成後已依需求重置測試存檔。遊戲目前使用 `ashen-guild-save-v2`，首次載入新版時會刪除舊的 `v1` 存檔並從第 1 日重新開始。

## 第六階段新增內容

- 三名角色各有兩條永久專精，共六種發展方向
- 角色達到 3 級後，可在遠征隊卡片選擇專精
- 新增墓穴毒蛛、殘光妖火與灰冠祭徒
- 新增中毒狀態、毒牙意圖與敵方治療意圖
- 專精可強化護盾、破勢、爆發傷害、探索收益或治療能力

## 第七階段新增內容

- 新增影刃、祈誓者與風槍手，公會共有六種職業可培養
- 透過酒館花費金幣招募新角色，自由編成三人遠征隊
- 每個角色擁有武器、護甲、飾品三個獨立裝備欄
- 十二件具有職業限制與不同屬性組合的裝備
- 背包支援重複物品、裝備替換與卸下
- 軍需處每日輪替四件裝備，並整合補給、設施與角色招募
- 只有實際出戰角色能取得遠征經驗

## 第八階段新增內容

- 裝備分為普通、稀有、史詩三種稀有度；高階商品由公會聲望解鎖
- 裝備擴充為十八件，加入首輪爆發、處決、破勢回能、治療回能、首次減傷、免死、燃燒擴散等十六種戰術詞綴
- 戰鬥有機率掉落裝備，高風險委託與終點戰鬥提高掉落機會
- 精英敵人可能具有爆裂、再生、狂怒或結界特性
- 狼群夾擊、流寇破盾、魔像守護、祭徒強化等敵人專屬行動
- 區域首領半血後進入第二階段，改用全隊橫掃
- 修正敵方護盾生命週期，現在可正確保護下一個玩家回合
- 難度主要來自行動組合、擊殺順序與裝備互動，而非單純堆高數值

## 第九階段新增內容

- 邊境、軍略、凶兆三種戰術難度，可在公會隨時切換
- 高難度增加精英密度、敵方特殊行動頻率或隱藏精確傷害，並提高報酬；不直接增加生命與攻擊
- 每次角色升級獲得能力結晶；能力結晶只用於角色能力加點
- 技能第一階強化自身效果，第二階降低一點技能消耗
- 新增區域、敵人與裝備圖鑑，內容需透過實際探索、遭遇及取得逐步解鎖
- 圖鑑顯示敵人戰術提示與整體收集進度

## 第十階段新增內容

- 六名角色各擁有六項一般技能與一道專屬絕招
- 每名角色可從六項技能中自由配置四項出戰技能
- 技能配置與既有兩階訓練系統共用，所有新增技能皆可培養
- 攻擊、施法與承受傷害會累積氣勢；達到 100 後可發動絕招
- 氣勢在同一次遠征的戰鬥之間保留，形成使用或保留的抉擇
- 新增反擊、完全閃避、持續恢復、復活、淨化、弱化及狀態增傷能力
- 六道絕招分別提供全隊防護、群體易傷、復活治療、群體處決、治療護盾與單體破勢爆發

## 第十一階段新增內容

- 線性遠征改為每個普通節點二選一的分支路線
- 巡邏路線提供穩定戰鬥；精英蹤跡保證敵人特性並提高戰利品；營地可恢復；未知岔路觸發事件
- 遠征終點固定為區域威脅，保留清楚的短期目標
- 低生命歸隊、撤退或戰敗可能造成可恢復的角色傷勢
- 撕裂傷、筋腱拉傷與魔力震盪分別影響生命、威力或技能點上限
- 傷勢隨遊戲日恢復，高等醫務室可加速休養，鼓勵輪替公會成員

## 執行方式

直接開啟 `index.html`，或在此資料夾執行：

```powershell
npx.cmd serve .
```

遊戲資料只儲存在瀏覽器的 `localStorage`，不會上傳。

## 手機安裝與離線遊玩（PWA）

PWA 必須透過 HTTPS 網址開啟，`localhost` 僅供電腦開發測試。發布到 GitHub Pages、Cloudflare Pages 或其他 HTTPS 靜態主機後：

- Android／Chrome：開啟遊戲後點頂部「安裝」，或從瀏覽器選單選擇「安裝應用程式」。
- iPhone／Safari：點「分享」→「加入主畫面」。遊戲內的「安裝方式」也會顯示這項提示。
- 第一次在線載入成功後，核心遊戲檔案會被快取；之後可從手機桌面離線啟動。
- 手機存檔仍保存在裝置瀏覽器中，可從「系統」匯出 JSON 備份。
- 發布新版後，重新連網開啟遊戲即可更新離線檔案。

PWA 相關檔案為 `manifest.webmanifest`、`service-worker.js`、`pwa.js` 與 `icons/`。

## 大型長期遊玩更新

- 四種七日季節輪替，會改變精英出現、掉落、商店與危機收益。
- 五個區域各自累積威脅；放任不管會形成高風險、高報酬的危機契約。
- 公會方針每五日輪替，鼓勵完成契約、獵殺精英、蒐集裝備或處理危機。
- 斥候塔、冒險者酒館、工匠作坊與戰利品陳列館各有三級功能性建設。
- 危機與高風險遠征會留下區域戰證；重大行動會寫入公會編年史。
- 狼煙丘陵與腐根沼地加入跨遠征延續的事件鏈，選擇會改變威脅、資源與紀錄。
- 舊版 `ashen-guild-save-v2` 存檔會自動補齊所有新欄位，不會清除既有進度。
- 「系統」選單可匯出 JSON 備份、匯入既有進度，或經雙重確認後刪除存檔重新開始。

## 成長與工坊重構

- 新增每日三項任務，戰鬥、契約、絕招、製作與分解都可能成為當日目標。
- 角色不再購買招募；里文、托爾與阿爾妲會在聲望達標時主動加入。
- 每次角色升級取得能力點，可分配體魄、力量與專注。
- 素材拆分為裝備、技能、能力三類：裝備使用鍛造素材，技能使用戰技殘頁與奧義印記，能力加點使用能力結晶。
- 敵我單位皆有 Buff／Debuff 狀態欄，清楚顯示層數、剩餘回合與效果。
- 戰鬥與技能訓練介面會列出目標、威力倍率、預估傷害、治療、護盾、破勢與狀態數值。
- 背包集中顯示鐵屑、韌布、灰燼精華、戰技殘頁、首領核心及未裝備物品。
- 裝備改由軍械箱抽取、遠征掉落或鐵匠鋪製作取得。
- 重複裝備能分解為素材；裝備可強化至 +5，直接提高基礎性能。
- 隊伍介面可以編成三人小隊並調整實際出戰順序。
- 公會建設改為斥候塔、大鍛造間、訓練庭與英雄檔案館。
- 音效改為共用音訊引擎，並加入低干擾的動態背景音樂。
